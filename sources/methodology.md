# Methodology

This log is generated, not written. Every number on a post page is computed
from the RoboCo task ledger (read-only SQL) or the public GitHub API, and
each post ships its raw computed facts as JSON beside it. If a sentence and
a JSON disagree, the JSON wins and the sentence gets corrected in the next
commit - posts themselves are immutable once written.

## Definitions

- **Completed work cycle**: a task carried from creation to completion
  through development, QA, and cell review - the `completed` transition in
  the task ledger, counted by `completed_at` on the UTC day.
- **Root PR**: a pull request merged into the source repository's root
  branch (`master`). Root merges are CEO-gated by design: only the human
  merges, so this count measures the org plus the operator's approval
  latency.
- **Release**: a GitHub release published on the source repository on that
  day. Releases are produced by the fleet's own release manager.
- **Awaiting decision**: board-program cycles whose exploration task is
  still non-terminal (the engine's own auto-close rule). Stale rows whose
  exploration finished are never shown as pending.
- **Provider spend**: rolling 7-day usage grouped by provider (the
  provider is derived from the model id with the same catalog rules the
  backend uses). Cost figures are the backend's `estimated_cost_usd`:
  usage attribution at published API rates, not cash out. Only Nebius,
  OpenRouter, and Grok rows are metered real spend; subscription
  providers (Anthropic, Z.ai, Ollama Cloud, Codex, Kimi, Gemini) bill
  fixed fees that appear on invoices at monthly reconciliation, not in
  these numbers.
- **Active vs idle**: a day is *active* when the ledger records at least one
  task transition that day; otherwise it is *idle*, and the post says so
  plainly. The idle cause is computed, not written: zero orchestrator
  dispatcher heartbeats (written every 5 minutes) means the stack was
  down; a paused-dispatch heartbeat flag or an unexpired maintenance_pause
  settings row means a deliberate operator pause; agent spawn failures or
  stalled tasks mean the fleet was up but failing; anything else is a
  healthy fleet with no work dispatched. Idle days are disclosed with
  cause, per the bridge agreement: a day verified down inside the bridge
  window (zero dispatcher heartbeats, or no post at all because the
  chronicler itself could not run) extends the window day-for-day,
  computed from the facts files and capped at seven days.

## Bridge floors

The 30-day window tracks four floors:

1. At least 40 completed work cycles.
2. At least 10 root PRs merged.
3. At least one fleet-shipped release (v0.31 or later).
4. At least one Auditor-initiated self-correction carried end to end.

The README scorecard updates the first three automatically from the facts
files. Floor 4 is narrative by nature - it is linked from the day post
where it happens rather than counted by a script.

## Provenance

- `sources/queries.sql` holds the exact SQL behind every count.
- Each post directory carries `facts-bod.json` / `facts-eod.json`: the full
  computed facts the post was rendered from.
- The narrative voice is generated by an LLM behind a fact-guard that
  rejects any sentence containing a numeral or URL absent from the facts
  JSON; when the guard fires, the post publishes without narrative.
